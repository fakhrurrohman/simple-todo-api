# Contributing

Terima kasih ingin berkontribusi! Langkah singkat:
1. Fork repo ini.
2. Buat branch: `fix/bug-<nomor>-yourname`
3. Perbaiki kode di folder `starter/`.
4. Jalankan `node starter/app.js` untuk mengetes.
5. Buat PR ke branch `main` dengan deskripsi apa yang Anda perbaiki dan mengapa.

Tiap PR fokus memperbaiki 1 bug. Jika ingin, tambahkan test singkat atau komentar.
